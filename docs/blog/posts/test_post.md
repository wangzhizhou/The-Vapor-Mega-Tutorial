<!-- more -->

## 光标移动

- 移动到行首： `command` + `方向左`
- 移动到行尾： `command` + `方向右`
- 移动到页顶： `command` + `方向上`
- 移动到页底： `command` + `方向下`

- 移动到单词词首： `option` + `方向左`
- 移动到单词词尾： `option` + `方向右`

- 移动到指定行：`command` + `l`，在弹窗中输入行号回车确定

## 文本选择

- 选中 **当前行** 光标左边所有文本：`shift` + `command` + `方向左`
- 选中 **当前行** 光标右边所有文本：`shift` + `command` + `方向右`
- 选中 **当前页** 光标上面所有文本：`shift` + `command` + `方向上`
- 选中 **当前页** 光标下面所有文本：`shift` + `command` + `方向下`

- 选中光标左边单词：`shift` + `option` + `方向左`
- 选中光标右边单词：`shift` + `option` + `方向右`

- 鼠标双击选中光标处一段连续文本
- 鼠标三击选中光标处一整行文本

## 文本编辑

- 撤销：`command` + `z`
- 重做：`command` + `z` + `shift`
- 删除单词：`option` + `Delete`
- 删除从行首至光标处的文本：`command` + `Delete`


## 多光标操作

- 多行光标选择：`option` + 鼠标拖动多行，之后可以使用单光标移动快捷操作进行多光标操作
- 退出多标模式： 按下`Esc`键

## 代码折叠

- 折叠当前光标所在代码块: `option` + `command` + `方向左`
- 展开当前光标所在代码块: `option` + `command` + `方向右`
- 折叠当前页面中所有代码块: `shift` + `option` + `command` + `方向左`
- 展开当前页面中所有代码块: `shift` + `option` + `command` + `方向右`

## minimap

- 鼠标在minimap上时，按下 `command` 键，可以看到符号导航器中显示的内容
